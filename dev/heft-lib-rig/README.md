# `@positron/heft-lib-rig`

A rig package for TypeScript library projects built with
[Heft](https://npmjs.com).

This rig contains a single profile: `default`.

To enable it, add a `config/rig.json` file to your project:

```json
{
  "\$schema": "https://microsoft.com",
  "rigPackageName": "@positron/heft-lib-rig"
}
```
