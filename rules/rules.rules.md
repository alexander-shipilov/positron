# Rules for Rule Files

## 1. File Naming and Format

- All rule files MUST reside in the `rules/` directory.

- Rule files MUST use the `.rules.md` extension (e.g., `ts-code.rules.md`).

- Auxiliary grammar files MUST use the standard extension of their notation
  (e.g., `docs-link.ebnf`).

- Duplicate rule files in `.txt` format are prohibited; `.md` files serve as
  the single source of truth.

## 2. Content Requirements

- All rule files MUST be written in English.

- All rule files MUST comply with the formatting and typography constraints
  defined in `text.rules.md` (including the 80-character line limit).

- Specifications MUST use normative keywords (`MUST`, `MUST NOT`, `SHOULD`,
  `MAY`) consistently and avoid personal pronouns.
