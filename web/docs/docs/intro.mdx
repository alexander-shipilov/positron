# Introduction

Welcome to the **Positron** documentation.

## Architecture

Positron is organized as a Rush monorepo with modular, strictly typed
TypeScript packages:

- **Shared libraries (`shared/*`)** — foundational type guards, assertions,
  nominal types, array/iterable helpers, and documentation tooling.
- **CSS & Styling (`css/*`)** — typed CSS value objects, units, and serialization.

## Generating API Reference

The **API Reference** section is generated automatically from compiled package
declaration models using `@positron/api-documenter`:

```bash
rush build
pnpm --dir web/docs start
```

Browse the generated contracts in the **[API Reference](./api/index.md)**.
